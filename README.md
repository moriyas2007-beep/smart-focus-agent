# ⚡ Smart Focus Agent

An AI-powered productivity and focus management agent based on the Pomodoro Technique, integrated with the Gemini API.

## 🎯 Key Features
- **Focus & Break Timers (Pomodoro):** Cycle tracking, audio notifications, and AI-generated break activity ideas.
- **Smart Task Management:** Daily and weekly task lists with automated AI task breakdown into daily sub-tasks.
- **Weekly Streak Tracker:** Visual progress tracking for daily goal completions and consistency.
- **AI Insights & Reports:** Generates encouraging daily summaries and comprehensive weekly productivity reports.
- **Customization:** Customizable color themes and ambient background sound tracks for improved concentration.
